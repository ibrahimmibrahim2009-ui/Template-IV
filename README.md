# Template IV 
### Instead of singular landing page for websites. By moving to integrated systems, The aim of the project is buliding integrated control panel of latest updates and works done for a company or user by managing real data from one place. 
## No Need For Ready Frameworks
### The main aim of the project is showing my ability to build and develop own framework from scratch. This was done by writing repeated classes I believe to use a lot.
## Multi-page Managing
### Dealing with 8 pages linked with each other depending on css only without need to JavaScript.
# Dashboard
## Brief collection for all activities: Quick statistics, latest news, daily tasks, latest uploads, and others.
# Settings
## Full control in account and system. It simulates settings page, where user can change his name and password. He can also link his social media accounts and control security info.
# Profile 
## The full identity of user in the plateform. This page shows the personal info, evaluation, technical skills, projects done, and timeline for latest activities for the user.
# Projects
## Follow current projects, specefied deadline for delivering, working team on it, progress bar, and ordered cost.
# Courses
## The educational track for user and systems. It includes cards displyaing the current cycles, the instructors, students number, price, and join button.
# Friends
## Ability to sociabelly communicate. It includes contact cards shows the role of each friend, number of proejects and comminicate buttons. 
# Files 
## Storage area, where files cards uploades with its name, extension, and others.
# Plans
## Comparative table between different plans in terms of available, and closed pros.
## Resposivity
### I don't have to say that the project is fully responsive at all media screens.

## Languages Used
